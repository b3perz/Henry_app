# QuickPlate

Fast meal planning for busy people. Pick your cook time, enter what's in your fridge, and get recipes in seconds.

## Live Site

https://b3perz.github.io/Henry_app/

## Setup (Local Dev)

```bash
npm install
npm run dev
```

Add your Anthropic API key in the app's Settings page — it's stored locally in your browser.

## Tech Stack

- React + Vite + Tailwind CSS v4
- Anthropic Claude API (claude-sonnet-4-20250514)
- GitHub Pages (static deploy via GitHub Actions)
- localStorage for preferences and API key
